# Lottery Analyst

所有统计、选号、核奖和回测必须运行本 Skill 的 Python 脚本，不得心算或编造。以本文件所在目录定位 `scripts/lottery_cli.py`，使用其绝对路径；Python 3.10+，仅需标准库。Windows 通常使用 `python`，macOS/Linux 通常使用 `python3`，先检查实际解释器。先读 [命令与计算口径](references/usage.md)，涉及规则、奖金和来源时读 [规则和来源](references/sources.md)。

- 彩种为 `ssq`（双色球）、`dlt`（大乐透）。使用明确的 `--db` 路径，放在用户工作目录，不写入 Skill 安装目录；持续操作复用同一数据库。
- 历史分析先 `sync` 自动获取官方数据，再 `stats`。输出实际首末期及数量，不宣称自发行以来全量覆盖。获取或校验失败时停止依赖步骤，说明错误，不编造或以缓存冒充新数据。使用缓存需用户接受并报告截至期号。
- 选号用 `generate`，默认 `uniform`、五组；统计约束用 `constrained`，多样性组合用 `diverse`。目标期号必须明确，不按日期猜测。若用户未给目标期，先同步/分析，再询问。无历史可用均匀随机或多样性模式，但不能描述为已经分析最新开奖。
- `generate` 自动记录时间、目标期、策略、数据摘要和版本。通常不指定种子，使用系统随机；可复现实验指定 `--seed`。不自动购买彩票或发送推荐。
- 复盘先 `sync` 再 `review --id`；单独核号用 `check`。必须读取官方目标期记录，奖金为 null 就是未知，不能补猜。双色球福运奖状态未知时脚本会拒绝相关核奖。
- 回测用 `backtest`，默认前 30 期预热、最多 100 期滚动训练。报告样本范围、参数、成本、命中分布及奖金缺失。不得用完整样本挑选参数后宣称是样本外验证。大乐透 19019 期之前的核奖规则尚未验证，会明确拒绝；早期号码可用于统计。

结果简洁注明：历史统计不能预测随机开奖，策略不保证或提高单注中奖概率。仅核单式基本/追加奖；不含派奖资格、税费、复式/胆拖，不把计算结果说成实际可兑付金额。
